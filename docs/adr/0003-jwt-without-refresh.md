# JWT-авторизация без refresh-токенов

Доступ к API — stateless JWT (HS256, срок жизни 7 дней), пароли хешируются Argon2.
Отзыв токенов и refresh-логика не реализованы: v1 — личное приложение без
многопользовательской нагрузки, а добавление refresh-логики позже не затронет
рутеры и фронт (меняется только `app/security.py` и `app/deps.py`).

**Considered Options**:
- **Opaque-токены в БД** — отклонены: запрос к БД на каждый запрос и таблица
  сессий ради отзыва, который пока не нужен.
- **JWT + refresh-пара** — отклонена до появления реальной потребности
  (длинные сессии, отзыв).

**Consequences**:
- Stateless: кэш/сессии между инстансами не нужны.
- Даунгрейд безопасности: скомпрометированный токен живёт до истечения 7 дней.
