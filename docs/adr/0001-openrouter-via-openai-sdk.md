# OpenRouter через OpenAI SDK, а не LangChain

Проект — тонкий прокси к Chat Completions: принимает сообщение, стримит ответ.
Используем пакет `openai` с `base_url="https://openrouter.ai/api/v1"`, потому что
OpenRouter совместим с OpenAI API: SDK отдаёт типизированные SSE-чанки, парсит
формат ошибок и запятые стрима за нас.

**Considered Options**:
- **LangChain** — отклонён: это оркестратор для агентов, цепочек и инструментов;
  для тонкого прокси добавляет тяжёлый слой абстракций и версионность без пользы.
- **Голый httpx** — возможен и содержит меньше зависимостей, но парсинг SSE
  (разделение событий, `[DONE]`, ошибки провайдера) пришлось бы писать руками.

**Consequences**:
- Формат чанков зафиксирован как OpenAI-совместимый; смена провайдера возможна
  среди API-совместимых (сейчас это практически все основные сервисы).
