# Issue tracker

GitHub Issues в `qwertylangs/ai-chat`, через `gh issue create` / `gh issue list` /
`gh issue edit`.

Триаж-лейблы: не настроены (скилл `triage` не установлен) — `ready-for-agent`
и другие ярлыки из шаблона `to-tickets` не применяются.

## История

До подключения repo issues заводились как файлы под `.scratch/<feature>/issues/`.
Что скопилось там — перенести вручную:
`gh issue create --title "..." --body-file .scratch/<feature>/issues/01-....md`,
затем удалить перенесённый файл.
