# AI Chat

Приложение для общения с LLM через OpenRouter: пользователь создаёт чаты, отправляет
сообщения и получает ответы ассистента потоком (SSE).

## Language

**Пользователь (User)**:
Учётная запись с уникальным именем, которой принадлежат чаты. Регистрируется
и входит по логину и паролю.
_Avoid_: юзер, аккаунт

**Токен доступа (Access token)**:
Удостоверение личности для запросов к API: выдаётся при входе, прикладывается к
каждому запросу и имеет ограниченный срок жизни.
_Avoid_: сессия, кука

**Чат (Chat)**:
Беседа одного пользователя с ассистентом; владелец единственный и неизменный.
Название задаётся пользователем либо, по умолчанию, берётся из первого сообщения.
_Avoid_: диалог, тред

**Сообщение (Message)**:
Запись внутри чата с ролью `user` или `assistant` и текстом. В истории чата
ассистентское сообщение появляется только целиком — после завершения генерации ответа.
_Avoid_: запись, реплика

**Стрим ответа (Stream)**:
Ответ ассистента, получаемый токенами по мере генерации, а не одним куском.
Пользовательское сообщение становится частью истории до начала стрима,
ассистентское — после его завершения.
_Avoid_: стриминг (жаргонное), поток

**Лимит токенов (Token limit)**:
Сколько токенов LLM пользователь может потратить за окно лимита — фиксированный
период (по умолчанию сутки UTC), по окончании которого расход обнуляется. Каждый
ответ ассистента расходует токены всей истории чата плюс самого ответа; при
исчерпании новые сообщения отклоняются до начала следующего окна.
_Avoid_: квота, баланс

**Модель (Model)**:
Конкретная LLM на стороне OpenRouter, запрашиваемая по имени; приложение не
привязано к какой-то одной модели (по умолчанию — `openai/gpt-4o`).
_Avoid_: движок, нейронка
